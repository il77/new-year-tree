# Стиль: объёмные гладкие объекты

Требование R12 (constraint «Объём и гладкость»): объекты сцены — объёмные
и гладкие, не плоские квадраты и не острые треугольники. Движок и подход
не меняются — 2D Canvas, ноль зависимостей; меняется только способ рисовать.
Документ — рабочий гид для эпиков `epic-scene`, `epic-garland`,
`epic-calendar`, `epic-world`.

## Правила

1. **Силуэт — скруглённый.** Прямоугольники и треугольники «в лоб»
   запрещены. Вместо них: `arc`/`ellipse`, скруглённый прямоугольник
   (углы через `arcTo`), кривые Безье (`quadraticCurveTo`/
   `bezierCurveTo`), плавный контур из нескольких точек.

2. **Объём — градиент + блик + тень.** Каждый объект получает:
   - базовый градиент (чаще радиальный — от освещённого края к затенённому);
   - блик — маленький светлый участок в сторону «света» (верх-слева);
   - мягкую тень снизу/справа (`shadowBlur` или полупрозрачный дубликат
     силуэта со смещением).

3. **Свет один на всю сцену.** Источник — верх-слева (звезда и огоньки
   сами по себе светятся: у них свечение-ореол, но блик всё равно
   верх-слева). Одинаковое направление блика у всех объектов складывает
   сцену в единое целое.

4. **Края мягкие.** Никаких жёстких 1px контуров-обводок. Свечение —
   слоями с убывающей непрозрачностью (паттерн `GLOW_LAYERS` в
   `src/spark.js` — образец). Дымка/туман между планами — полупрозрачные
   градиенты.

5. **Тени — мягкие.** `ctx.shadowBlur` со `shadowColor` той же семьи
   цветов, что и объект, либо второй проход силуэта с увеличенным
   радиусом и низкой непрозрачностью.

## Рецепты

### Шар (огонёк, снежинка-капля)

```js
function drawBall(ctx, x, y, r, color) {
  // Основной объём: радиальный градиент, центр — блик верх-слева
  const g = ctx.createRadialGradient(x - r * 0.35, y - r * 0.4, r * 0.1, x, y, r);
  g.addColorStop(0, '#ffffff');      // блик
  g.addColorStop(0.35, color);       // основной тон
  g.addColorStop(1, shade(color, 0.45)); // затенённый край
  ctx.beginPath();
  ctx.arc(x, y, r, 0, Math.PI * 2);
  ctx.fillStyle = g;
  ctx.fill();
}
```

### Скруглённый прямоугольник (окно, корпус фонарика)

```js
function roundRect(ctx, x, y, w, h, r) {
  ctx.beginPath();
  ctx.moveTo(x + r, y);
  ctx.arcTo(x + w, y, x + w, y + h, r);
  ctx.arcTo(x + w, y + h, x, y + h, r);
  ctx.arcTo(x, y + h, x, y, r);
  ctx.arcTo(x, y, x + w, y, r);
  ctx.closePath();
}
```

### Мягкий конус (ярусы ёлки — без острых треугольников)

Каждый ярус — не треугольник, а «подол»: боковые стороны — кривые
Безье с отклонением наружу, низ — дуга вниз. Заливка — вертикальный
градиент (светлее сверху, темнее к низу) + блик слева.

```js
function drawTier(ctx, cx, topY, bottomY, halfW) {
  const bulge = halfW * 0.18; // нижний подол выпукл вниз
  ctx.beginPath();
  ctx.moveTo(cx, topY);
  ctx.quadraticCurveTo(cx - halfW * 0.75, bottomY - (bottomY - topY) * 0.25, cx - halfW, bottomY);
  ctx.quadraticCurveTo(cx, bottomY + bulge, cx + halfW, bottomY);
  ctx.quadraticCurveTo(cx + halfW * 0.75, bottomY - (bottomY - topY) * 0.25, cx, topY);
  ctx.closePath();
  // ... градиентная заливка
}
```

### Ореол свечения (для светящихся объектов)

Три-четыре концентрических `arc` с падающей непрозрачностью
(как `GLOW_LAYERS`), поверх — объект с бликом. Радиус ореола в 4–6 раз
больше радиуса ядра.

## Проверка себя

- Убрать градиенты → объект всё ещё читается как форма? (силуэт скруглён)
- Блики у всех объектов в одном направлении?
- Нет ни одного `fillRect` для объектов сцены (фон и маски — исключение)?
- Нет обводок `stroke` толщиной 1px на силуэтах?
