# Народная ёлка — новогодний сайт

Статическая тёмная страница с искрой «зажги» на 2D Canvas. Без внешних
зависимостей рендера: только встроенный Canvas 2D браузера и стандартные
средства Node для тестов и запуска.

## Требования

- Node.js 22+ (используются `node:test` и `node:fs/promises`)
- Браузер с поддержкой 2D Canvas

Устанавливать зависимости не нужно: `npm install` не требуется
(runtime- и dev-зависимостей нет).

## Локальный запуск (проверка человеком)

```sh
npm run dev
```

Открыть <http://localhost:5173> (порт можно переопределить: `PORT=8080 npm run dev`).

Ожидание: чёрный экран, одна жёлто-белая искра выше центра, подпись «зажги»;
по касанию/клику в любом месте искра падает и проявляется мир — снег, лес и
ёлка (ритуал первого входа). Дальше сцена живёт: снег падает, огоньки ёлки
мерцают, камера слегка покачивается. Повторное открытие в том же браузере
сразу показывает готовый мир без ритуала. Ошибок в консоли нет.

Альтернатива без скрипта: `python3 -m http.server 5173` — и открыть
<http://localhost:5173>.

## Тесты

```sh
npm test
```

`node:test` проверяет на мок-2D-контексте рендер искры (свечение, лучи),
контракт рендера (регистрация, порядок слоёв), ритуал первого входа
(машина состояний, тайминг проявления, флаг localStorage, ветки ошибок
хранилища и деградации), повторный вход (готовый мир с первого кадра,
касания — no-op, ровно один цикл от bootstrap, без лишних кадров) и живую
сцену (камера, падение снега, мерцание огоньков — детерминированы по
времени; один rAF-цикл, пауза скрытой вкладки, деградации). Ожидание:
все тесты зелёные, exit 0.

## Сборка

```sh
npm run build
```

Копирует `index.html` и `src/` в `dist/` без ошибок; `dist/` можно отдавать
как статику любым хостингом. Папка `docs/` — repo-only: документация и
концепт-мок в `dist/` не попадают (до story 2.6).

## Контракт рендера сцены

Способ добавить свой объект на сцену (для эпиков 2–4) описан в
[docs/contract.md](docs/contract.md): регистрация через
`sceneContract.register(draw, { layer })`, параметры draw-функции
`(ctx, width, height, t)` и порядок отрисовки кадра (фон → искра →
слои объектов).

Визуальный стиль — объёмные гладкие объекты (скруглённые силуэты,
градиенты, блики, мягкие свечения; без плоских квадратов и острых
треугольников): [docs/style.md](docs/style.md), концепт-мок —
[docs/design-final.html](docs/design-final.html).

## Структура

Документация в `docs/` — repo-only: в `dist/` не попадает (до story 2.6).

- `index.html` — страница-точка входа: full-screen canvas, подпись «зажги», тёмный фон; синхронная проверка флага повторного входа до загрузки модуля
- `src/spark.js` — чистая функция `drawSpark(ctx, x, y, t, alpha)` (тестируемое ядро)
- `src/scene.js` — чистый кадр: `renderFrame(ctx, w, h, t, contract, ritual)` + позиция искры `sparkAt(w, h)` (долями экрана)
- `src/contract.js` — контракт рендера: `createSceneContract()` (фабрика для тестов) и общий `sceneContract` для страницы
- `src/ritual.js` — ритуал первого входа: машина состояний dark → falling → revealed, тайминг, флаг `ny_tree_first_visit` (localStorage)
- `src/animation.js` — живая сцена: чистая математика движения по времени `t` — камера (покачивание), падение снежинок, мерцание огоньков
- `src/world.js` — объекты мира (снег, лес, ёлка) по docs/style.md и их регистрация слоями (5 → 8 → 10)
- `src/main.js` — `bootstrap(doc, win, contract)`: размер canvas, ресайз, деградация без 2D, единый rAF-цикл (ритуал + постоянная анимация), пауза скрытой вкладки, обвязка касания/флага; в браузере выполняется сам
- `docs/contract.md` — документ контракта для эпиков 2–4
- `docs/style.md` — визуальный стиль: объёмные гладкие объекты (рецепты рендера)
- `docs/design-final.html` — концепт-мок финального состояния ёлки
- `test/spark.test.js` — тесты рендера искры (`node:test`)
- `test/matrix.test.js` — тесты матрицы I/O: первый рендер, ресайз, нет canvas 2D, структура страницы
- `test/contract.test.js` — тесты контракта: регистрация, порядок слоёв, невалидные аргументы
- `test/ritual.test.js` — тесты ритуала первого входа: шаги времени, флаг, ошибки localStorage, деградации
- `test/repeat.test.js` — тесты повторного входа: готовый мир с первого кадра, no-op касаний при revealed, ровно один цикл без лишних кадров, деградации, инлайн-скрипт подписи
- `test/live.test.js` — тесты живой сцены: камера/снег/мерцание (детерминизм по t), единый rAF-цикл, вкладка-пауза, деградации
- `scripts/serve.js`, `scripts/build.js`, `scripts/mock-ctx.js` — локальный сервер, сборка и общий мок 2D-контекста для тестов, без зависимостей
