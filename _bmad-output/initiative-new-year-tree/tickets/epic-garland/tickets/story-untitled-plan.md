## Intent

**Problem:** Сейчас сайт показывает общую ёлку без всякого вклада посетителя: нет ни серверного визита, ни счётчика, ни огонька гирлянды. Без одного сквозного пути от запроса до кадра последующие истории (10→1, раскладка по дате) не на что опереть.

**Approach:** Один запрос визита к тому же процессу, что отдаёт статику: сервер хранит число входов файлами и возвращает счётчик с seed от даты/времени; клиент показывает счётчик внизу страницы и регистрирует один огонёк через контракт рендера на слое 20. Движок — 2D Canvas, без зависимостей.

## Boundaries & Constraints

**Always:** один процесс отдаёт статику и запрос визита, `npm run dev` работает как раньше; ноль runtime/dev-зависимостей, Node 22+, тесты на `node:test`; контракт рендера и ритуал epic-scene остаются как есть; огонёк регистрируется через `sceneContract` со слоем 20; стиль R12 — скруглённый силуэт, радиальный градиент, блик верх-слева, мягкое свечение; данные живут файлами в папке на сервере, не в localStorage, не попадают в сборку и не коммитятся.

**Never:** не блокировать повторные входы и не считать визиты в браузере; не создавать второй rAF-цикл и не рисовать на canvas вне контракта; не добавлять `fillRect` в слой объектов (сломает зафиксированные счётчики кадров в существующих тестах) и не трогать `#caption`/`#fallback`; не делать схлопывание 10→1, раскладку по дате, цвет недели, сияние ёлки и публикацию на адресе — это stories 2.2, 2.3, 2.6.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Первый визит | Пустая папка данных | `POST /api/visit` → JSON `count: 1`, `seed`; файл создан; внизу «1», на ёлке один огонёк | Нет ошибки |
| Визит из второго браузера | В файле `count: 1` | Ответ `count: 2`; после обновления обе вкладки видят «2» и по одному огоньку | Нет ошибки |
| Сервер недоступен | `fetch` отклонён | Сцена и ритуал работают, счётчик показывает «—», один огонёк рисуется от локального seed | Ошибка проглочена, в консоли тихо |
| Закрытый путь | `GET /data/…` или путь с `../` | `404`; раздача статики, MIME и защита от обхода не сломаны | Ответ 404 без утечки файла |

**Acceptance Criteria:**
- Given пустая папка данных, when пришёл `POST /api/visit`, then ответ содержит `count: 1` и `seed`, а файл создан.
- Given в файле `count: 1`, when приходит второй запрос, then ответ `count: 2`; два браузера после обновления видят одно число и по одному огоньку.
- Given `fetch` отклонён, when загружается страница, then ритуал и живая сцена работают, счётчик показывает «—», консоль чистая.
- Given изолированный контракт, when вызван `registerGarland`, then `contract.size` вырос на 1, слой равен 20, кадр даёт один градиентный шар с бликом и ореолом и ни одного `fillRect`.
- Given запрос к `/data/…` или `../`, when сервер отвечает, then `404` и статика отдаётся как раньше.

## Design Notes

Один JSON-файл хранит `count` и последний `seed`; seed пока не влияет на координаты — его потребитель появится в story 2.3. Фабрика обработчика принимает папку данных параметром: тесты используют временную папку и не портят рабочую.
