## Intent

**Problem:** Сцена показывает темноту с искрой «зажги», но касание ничего не делает: нет порог-сотворения (R9/R1) — мира вокруг ёлки нет вообще, нет способа запомнить первый вход в браузере.

**Approach:** Ритуал как чистая машина состояний `dark → falling → revealed` в отдельном модуле `src/ritual.js` (детерминирована по `t` в мс); при касании искра падает (~800 мс), за ней послойно проявляются снег → лес → ёлка (~2.05 с с задержками), объекты мира регистрируются через `sceneContract` слоями и рисуются по R12 (`docs/style.md`). DOM/localStorage — тонкая обвязка в `src/main.js`. После ритуала ставится флаг `ny_tree_first_visit` — story 1.4 читает его одним вызовом.

## Boundaries & Constraints

**Always:** ноль зависимостей (node:test, мок-ctx); логика ритуала — чистый модуль с функциями `startRitual`/`updateRitual`/`ritualProgress`, детерминированными по `t`; объекты мира — через `sceneContract.register` со слоями (снег ниже леса и ёлки, гирлянда позже ляжет поверх); R12: скруглённые силуэты, градиенты, блик верх-слева, мягкие тени, без `fillRect` для объектов (фон/маски — исключение); вход тихий: без модалок, звуков и требований сверх «коснись искры»; все 14 старых тестов зелёные.

**Never:** никакой гирлянды, звезды, календаря, счётчиков (эпики 2–4), никакой постоянной анимации (story 1.5), никаких поп-апов/звуков/клавиатурных ловушек; git-операций не выполняет агент; `sceneContract` в Node-тестах не засоряется регистрациями (старый тест `contract.test.js` на `size === 0` остаётся истиной).

## Implementation Notes

- **Ядро — `src/ritual.js`**: `startRitual`/`updateRitual`/`ritualProgress` чистые и детерминированы по `t`; `createRitual({ firstVisit })` — фабрика-холдер (изоляция тестов, как `createSceneContract`). Прогресс отдаёт `{ phase, spark: { yRatio, alpha }, layers: { snow, forest, tree } }` — рендер и объекты мира не знают друг о друге, только берут прогресс по своему `t`.
- **Обвязка — `src/main.js`**: `bootstrap` возвращает `{ render, contract, ritual }` (старые тесты проверяют только `render`/`contract` — совместимо). Касание вешается на canvas (`pointerdown` + запасные `touchstart`/`mousedown`) с guard'ом на `addEventListener`; цикл — на rAF с guard'ом; `render()` без аргумента по-прежнему отдаёт `t = 0` (старые тесты ресайза), во время ритуала ресайз-кадр берёт `now()`.
- **Мир — `src/world.js`**: `registerWorld(contract, progressAt)` регистрирует три объекта слоями 5/8/10; слой пропускается при `alpha === 0` (в темноте кадр не содержит ни одного вызова мира). Цвета-маркеры (`WORLD_COLORS`) экспортируются — тесты распознают слои по градиентным стопам. Снежинки и силуэт леса — детерминированный `hash01` (никакого `Math.random` — кадр воспроизводим в тестах).
- **Регистрация на странице**: `if (page) { registerWorld(...); page.render(); }` — вне браузера `page === null`, общий `sceneContract` не трогается, старый тест «общий экземпляр не засорён регистрациями» проходит без правок (это же и был главный архитектурный конфликт story: контракт требует регистрацию на уровне модуля, старый тест — не засорять общий экземпляр в Node; разрешён поздней регистрацией на странице, задокументированной в docs/contract.md).
- **Искра**: `drawSpark` получил необязательный `alpha` — при `<= 0` ранний выход (в готовом мире искры нет), при `(0, 1)` — `globalAlpha` с восстановлением; без альфы поведение не изменилось (старые тесты искры проходят байт-в-байт).
- **Старые 14 тестов не менялись ни одной строкой** — и проходят.

## Design Notes

**Тайминг (фиксация).** Падение искры: `FALL = 800 мс` (в диапазоне 700–900); позиция — ease-in (квадрат, ощущение свободного падения), альфа — линейный фейд в последних 30% времени падения, к концу искра гаснет у земли (`yRatio 0.42 → 0.78`). Проявление мира: снег со 200 мс, лес с 650 мс, ёлка с 1100 мс, каждый слой проявляется 950 мс со smoothstep — ёлка «дозревает» на 2050 мс, суммарно ≈ 2.05 с (в диапазоне 1.5–2.5 с), старт слоёв перекрывает падение, так что мир начинает проступать ещё за падающей искрой. Фаза `revealed` наступает по `RITUAL_TOTAL` (конец проявления, а не конец падения).

**Ветка ошибки localStorage — «первый вход каждый раз».** Обоснование: ритуал короткий (~2 с), тихий, без преград и не блокирует просмотр — его повторность безвредна; а вот обратная ветка (ошибка = «пройдено») показала бы миру без порог-сотворения (R9), то есть потеряла бы ядро концепции ровно у тех пользователей, у кого что-то не так с браузером. Плюс семантика флага не «разрешено показать», а «ритуал уже сыгран» — при неизвестном состоянии честнее сыграть заново.

**Флаг.** Ключ `ny_tree_first_visit`, значение `"1"`; пропуск — только точное `"1"` (битое/пустое/чужое значение = первый вход, не падаем). Story 1.4 = одно чтение `readFirstVisit(storage)` (уже в `bootstrap`).

**Зона касания — вся тёмная страница.** Точно попадать по искре на тач-экране неприятно и противоречит «тихому входу»; слушатели висят на canvas (он во весь экран), любое касание до `revealed` запускает ритуал, дальше — идемпотентный no-op.

**Контроллер и чистота.** `startRitual`/`updateRitual`/`ritualProgress` — чистые, состояние `+t → состояние`; `createRitual` — фабрика-холдер (изоляция тестов, как `createSceneContract`); DOM/localStorage/rAF только в `main.js`, всё через аргументы (`storage` — объект, не глобал).

**Регистрация мира.** `if (page) registerWorld(page.contract, (t) => page.ritual.progress(t)); page.render();` — поздняя регистрация, задокументированная в `docs/contract.md`; вне браузера `page === null`, общий экземпляр не трогается (старый тест `contract.test.js` «общий экземпляр не засорён регистрациями» остаётся зелёным без правок). Слои: снег 5 → лес 8 → ёлка 10 < гирлянда 20 (epic-garland).

**Ощущение.** Мягкость: smoothstep на всех проявлениях, подъём слоёв на 1–1.5% высоты по мере проявления, блик у каждого объекта верх-слева, подпись гаснет fade'ом 700 мс (не исчезает мгновенно), курсор `pointer` на тёмной странице как тихая affordance.
